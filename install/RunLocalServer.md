
# 环境操作指南

## 启动步骤

1. **启动本地测试环境**

   ```bat
   tools\script\start_local_test_env.bat
   ```
2. **启动所有服务**

   ```bat
   start_all.bat
   ```

## 关闭步骤

1. **停止所有服务**

   ```bat
   stop_all.bat
   ```
2. **强制停止所有服务（必要时使用）**

   ```bat
   kill_all.bat
   ```
3. **停止本地测试环境**

   ```bat
   tools\script\stop_local_test_env.bat
   ```
